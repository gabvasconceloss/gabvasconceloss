# Sobre mim

Sou **Gabriel Vasconcelos**, Técnico em Informática pela Fundação Mathias Machine e estudante de **Engenharia de Software pela Fametro**.

Atualmente, atuo como **estagiário de desenvolvimento no SIDIA**, trabalhando com desenvolvimento de software e tendo como principais áreas de atuação **React e Android**.

Minha trajetória envolve desenvolvimento de aplicações web e mobile, construção de interfaces, integração com APIs, desenvolvimento de funcionalidades e exploração de diferentes tecnologias do ecossistema de desenvolvimento de software.

Além da experiência profissional, atualmente estou aprofundando meus conhecimentos em **Python**, buscando fortalecer minha base de programação, lógica, algoritmos e estruturas de dados.

Gosto de transformar ideias em produtos funcionais, explorar novas tecnologias e entender não apenas como implementar uma solução, mas também como estruturar e evoluir um software.
